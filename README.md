The shared repository of the **مطوّري إشراقة · Ishraqa Developers** developers club on Ishraqa.
Club page: https://ishraqa.app/club/?c=357ead25

## How we work

1. **Issues first.** Every idea, bug or task starts as an issue. Comment on it to claim it, so nobody duplicates work.
2. **Branch.** Create a branch from `main` named after the issue, for example `12-login-screen`.
3. **Pull request.** Open a PR that links the issue (`Closes #12`) and explains *what* changed and *why*.
4. **Review.** At least one club lead or another member reviews every PR before it is merged. Be kind, be specific.

## Good first issues

New to the club? Open the **Issues** tab and filter by the `good first issue` label.
They are small, well described, and a lead is happy to guide you through your first PR.

## Joining

Link your GitHub username in your Ishraqa developer profile, then ask a club lead to sync members.
You will receive an invitation to this repository.
